# Terminología

**Versión:** 1.0  
**Estado:** Aprobado

## Propósito

Define las definiciones oficiales utilizadas en Jorkcáceres OS.

### Capacidad
Conjunto de conocimientos, experiencia y habilidades que Jorkcáceres utiliza para ayudar a una empresa a alcanzar un objetivo de negocio.

### Modalidad
Forma específica en la que se implementa una capacidad.

### Herramienta
Tecnología utilizada para implementar una solución.

### Solución
Respuesta diseñada para resolver un problema o alcanzar un objetivo de negocio.

### Diagnóstico Estratégico
Proceso mediante el cual comprendemos el negocio antes de recomendar una solución.

### Consultor Estratégico
Modelo de razonamiento utilizado para comprender, analizar y recomendar soluciones alineadas con los objetivos del negocio.

### Objetivo de Negocio
Resultado que la empresa desea alcanzar.

### Madurez
Nivel de integración que tiene la tecnología dentro de los procesos de una empresa.

### Activo Digital
Conocimiento, metodología, componente o solución reutilizable desarrollada por Jorkcáceres que fortalece sus capacidades y constituye parte de su propiedad intelectual.

### Implementación
Proceso mediante el cual una solución es llevada a la práctica.

### Automatización
Uso de tecnología para reducir o eliminar actividades manuales.

### KPI
Indicador clave utilizado para medir el desempeño de un objetivo de negocio.

### Dashboard Gerencial
Herramienta de visualización diseñada para facilitar decisiones mediante información clara, relevante y adaptada al usuario.

### MVP
Versión simplificada de una solución utilizada para validar una idea de negocio con la menor inversión posible.

### Validación de Ideas
Modalidad de Soluciones Digitales orientada a comprobar una idea de negocio en el mercado.

### Solución a la Medida
Modalidad de Soluciones Digitales orientada a construir una solución para una necesidad particular de una compañía.

### Cliente Ideal
Emprendedores, pequeñas empresas y medianas empresas que quieren hacer uso de la tecnología para crecer y no saben cómo hacerlo.

### Valor
Beneficio real que una solución genera para el negocio.
