# Activos Digitales

**Versión:** 1.3  
**Estado:** Aprobado

## Propósito

Los Activos Digitales representan el conocimiento, las metodologías, los componentes y las soluciones reutilizables que Jorkcáceres desarrolla para fortalecer sus capacidades y generar mayor valor.

## Qué es un Activo Digital

Es cualquier elemento desarrollado por Jorkcáceres que pueda reutilizarse, evolucionar con el tiempo y aumentar el valor de la organización.

No es un entregable de cliente ni un proyecto específico.

## Ejemplos

- frameworks;
- metodologías;
- prompts;
- plantillas;
- investigaciones;
- componentes reutilizables;
- MVPs;
- modelos;
- productos o soluciones propias.

## Cómo nace

Puede surgir cuando:

- un conocimiento se reutiliza;
- una metodología demuestra valor;
- un componente puede utilizarse en distintos proyectos;
- una investigación produce un modelo aplicable;
- una idea evoluciona hasta convertirse en un producto.

No todos los proyectos generan un Activo Digital.

## Estados

- Idea
- Investigación
- Desarrollo
- Validación
- Consolidado
- Evolución

## Estructura

Cada activo puede organizarse mediante:

```text
JC-001/
├── Modelo JC
├── Investigación
├── Desarrollo
├── Roadmap
└── Aprendizajes
```

## Principios

### Reutilizable
Debe poder aportar valor más allá de un proyecto.

### Útil
No se documenta por obligación.

### Evolutivo
Puede mejorar con la experiencia.

### Comprensible
Debe poder entenderse sin depender del proyecto donde nació.

### Estratégico
Debe fortalecer las capacidades o propiedad intelectual de Jorkcáceres.

## Activos registrados

### JC-001 · Portal Jorkcáceres

Plataforma propia para dar continuidad a la relación con clientes después del contacto inicial. Integra encuestas públicas, acceso autenticado para clientes y administración de información operativa.

- **Estado:** Consolidado.
- **Versión actual:** 1.2, base estable.
- **Capacidad principal:** Soluciones Digitales.
- **Conocimiento asociado:** experiencia de cliente, servicios recurrentes, pagos, diagnóstico digital, modelos de decisión, arquitectura, seguridad, operación, QA y despliegue.
- **Documento:** [Portal Jorkcáceres](activos/Portal_Jorkcaceres.md).

### JC-002 · Propiedades CM

Aplicación web privada para administrar viviendas arrendadas, relaciones contractuales, pagos y comprobantes verificables. Conserva información vigente para operar y snapshots inmutables para proteger la evidencia histórica.

- **Estado:** Producción operativa.
- **Versión actual:** 0.6.2.
- **Capacidad principal:** Soluciones Digitales.
- **Conocimiento asociado:** permisos por acción, trazabilidad financiera, documentos privados, snapshots, auditoría, experiencia mobile first y operación de un producto propio.
- **Documento:** [Propiedades CM](activos/Propiedades_CM.md).
